## FAQ

- Subheading: FAQ
- Title: Questions fréquentes
- Items:
  1. Item 1
    - Question: Quels sont les délais de création d'un site web ?
    - Answer: Les délais de création d'un site web varient en fonction de la complexité du projet. Nous établissons un planning détaillé dès le début du projet. Les délais moyens sont de 3 à 6 semaines.
  2. Item 2
    - Question: Comment le prix d'un site web est-il déterminé ?
    - Answer: Le prix d'un site web dépend de 3 critères majeurs : la complexité du projet, les fonctionnalités demandées, le design. Nous établissons un devis personnalisé en fonction de vos besoins.
  3. Item 3
    - Question: Comment s'organise le paiement ?
    - Answer: Le paiement s'effectue en 2 étapes : un acompte de 50% à la signature du devis, puis le solde à la livraison du site web.
  4. Item 4
    - Question: Quels sont les éléments à fournir ?
    - Answer: Il est recommandé de fournir un logo, des images et textes pour le contenu du site web. Nous pouvons également vous accompagner dans la création de ces éléments.
  5. Item 5
    - Question: Le site m'appartient-il légalement ?
    - Answer: Oui, une fois le solde payé, le site web vous appartient légalement. Vous êtes libre de le faire évoluer comme bon vous semble.
  6. Item 6
    - Question: Comment héberger mon site web ?
    - Answer: Le prix de l'hébergement est inclus dans nos devis. Nous nous chargeons de l'installation et de la configuration de votre site web sur un serveur adapté à vos besoins.
  7. Item 7
    - Question: Mon site sera-t-il visible sur Google ?
    - Answer: Oui, nous optimisons votre site web pour le référencement naturel afin qu'il soit visible sur les moteurs de recherche comme Google, Yahoo, Bing ou encore DuckDuckGo.
  8. Item 8
    - Question: Mon site sera-t-il adapté aux mobiles ?
    - Answer: Oui, tous les sites web que nous créons sont responsive design, c'est-à-dire qu'ils s'adaptent automatiquement à tous les types d'écrans (ordinateurs, tablettes, smartphones).
  9. Item 9
    - Question: Puis-je modifier le contenu de mon site web ?
    - Answer: Inclus dans le forfait de maintenance, vous pouvez nous contacter à tout moment pour effectuer des modifications ou des mises à jour sur votre site (images, textes).
